# 产品规格：后台操作员账号创建

> 状态：DRAFT｜版本：1.0｜日期：2026-09-04
> Feature：`admin-operator-account-creation`｜规模：Small

## 1. 概览

### 问题

当前“新建后台操作员”要求管理者填写 `auth_subject_id` UUID。UUID 是内部技术标识，管理者通常无从获得或验证；页面也无法创建新后台登录账号，导致操作流程不完整。

### 方案

在现有“新建操作员”弹窗中收集用户名和显示名称。系统在同一受控流程中创建独立后台登录账号、创建其 Operations Operator 映射，并随机生成一次性初始密码；操作者随后在既有页面分配角色。

### 已确认边界

- 后台账号不依赖、也不提升 Mobile 用户。
- 本次不做邀请、邮件/短信通知、MFA、企业 SSO 或独立账号管理页。
- 继续使用 Identity 的后台认证边界、Operations 的 Operator/RBAC 边界和现有密码规则；不新增数据库表。

## 2. 使用者

具备 `operations.operators.create` 权限的已登录后台管理员，在为新同事开通后台访问时使用本功能。

## 3. 用户故事

- **US-001**：作为有创建权限的后台管理员，我要填写用户名和显示名称创建后台操作员，并复制系统生成的一次性初始密码，以便新同事无需 Mobile 注册或手填 UUID 即可取得后台登录账号。 <!-- CR-001: 随机生成并仅当次展示初始密码 -->
- **US-002**：作为创建者，我要在用户名已存在或提交失败时得到清晰提示，以便修正输入且不留下不可用账号。 <!-- CR-001: 密码由系统生成，不再由创建者输入 -->
- **US-003**：作为安全负责人，我要确保只有持有创建权限的管理员能创建账号，并且创建失败会整体回滚，以便账号与 Operator 映射不会出现孤立状态。

## 5. 验收场景

### FR-003-AS01：创建独立后台账号

**Given** 已登录管理员拥有 `operations.operators.create`，且用户名未被使用，
**When** 管理员提交有效的用户名和显示名称，
**Then** 系统创建后台登录账号及 active Operator，并在当次成功界面展示可复制的一次性初始密码；列表显示该操作员，且可使用该用户名和密码登录后台。 <!-- CR-001: 随机生成并仅当次展示初始密码 -->

### FR-001-AS01：不暴露 UUID

**Given** 管理员打开“新建操作员”，
**When** 页面完成渲染，
**Then** 页面不显示 `auth_subject_id` 或 UUID 输入框，提交载荷也不包含它。

### FR-005-AS01：重复用户名

**Given** 已存在相同用户名的后台账号，
**When** 管理员尝试创建，
**Then** 页面提示用户名不可用，且不创建新的 Operator。

### FR-008-AS01：一次性密码不再可见

**Given** 后台账号已成功创建，
**When** 创建者关闭成功提示、刷新页面或之后重新访问操作员列表，
**Then** 系统不再返回或显示该初始密码。 <!-- CR-001: 随机生成并仅当次展示初始密码 -->

### FR-007-AS01：无权限拒绝

**Given** 已登录操作员不具备 `operations.operators.create`，
**When** 其尝试调用创建接口，
**Then** 服务端拒绝请求，且不创建任何账号或 Operator。

## 6. 非功能与安全要求

- 随机密码只能通过受保护响应在创建成功时返回一次；不得被日志、审计详情、错误文本或前端持久化状态记录。 <!-- CR-001: 随机生成并仅当次展示初始密码 -->
- Identity 和 Operations 的跨域协作必须通过既有公开边界；Operations 不得直接写入 Identity 数据。
- 创建动作必须具备原子性或可证明的补偿，禁止出现仅有账号或仅有 Operator 的可见中间状态。
- 键盘可操作、标签与错误关联继续使用现有 FormField 交互模式。

## 7. 风险与待技术确认

| 风险 | 缓解方式 |
| --- | --- |
| 新 API 需与既有调用方同步切换 | ADR-025 已授权修订同一路径的请求/响应；技术方案与测试必须覆盖 Admin 前后端同步切换。 |
| 双域写入可能产生部分成功 | ADR-025 已定义同库本地事务与窄写入端口；以集成测试证明每个失败分支都会回滚。 |
| 初始密码泄露 | 复用现有强度校验和哈希机制，禁止记录明文。 |
