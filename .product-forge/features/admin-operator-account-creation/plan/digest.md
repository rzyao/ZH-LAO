# Phase Digest：技术方案

## 关键决定

- ADR-025 将同一路径改为受控账号与 Operator 创建命令。
- 应用装配层编排 Identity 与 Operations 的窄写入端口，使用同一数据库本地事务。
- 初始密码由加密安全随机源生成，成功响应一次性返回；客户端仅以内存状态展示。

## 产出

- `plan.md`：HTTP、事务、域边界、前端、验证及风险方案。

## 开放风险

- 需要在实现时验证组合根能注入编排器而不造成模块循环。
- 初始密码遗失后的重置能力不在本次范围。

## 交接

- 实现应先完成后端事务性编排与集成测试，再切换 Admin 请求和 Dialog。
- 不得改动冻结迁移；不得把事务执行器或 Repository 公开给跨 Domain 调用方。
- Prior lessons applied：none。
