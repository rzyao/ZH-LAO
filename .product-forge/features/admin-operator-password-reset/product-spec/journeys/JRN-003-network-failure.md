# JRN-003：网络失败后不自动重试或恢复秘密

**Actor：** 已发起重置的后台管理员。  
**前置条件：** 提交后浏览器未收到可解析的成功响应。

| Step | Action | Expected result | Component / contract |
| --- | --- | --- | --- |
| STEP-008 | 客户端处理网络失败 | 不自动重试；不显示或缓存密码；保留安全错误与刷新入口 | CMP-Toast |
| STEP-009 | 管理员刷新目标状态 | 可明确发起新的重置，但无法通过读取恢复旧的临时密码 | API-RESET |

**EDGE-006（P0）：** Given 服务端已提交但响应丢失，When 客户端恢复连接，Then 不重放命令且不以任何读取接口返回秘密。
