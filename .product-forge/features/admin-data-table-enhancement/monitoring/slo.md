# 批量字母审核 SLO

> Owner：Content｜状态：发布前需接入实际监控平台

| SLI | 目标 | 观察窗口 | 证据来源 |
| --- | --- | --- | --- |
| 列表查询可用性 | ≥99% 成功且无内部错误 | 30 天 | `GET /lo/letters` 日志/指标 |
| 列表查询延迟 | p95 ≤500 ms | 10 分钟滚动 | API 延迟指标 |
| 批量任务完成性 | 无未解释的 `queued/running` 任务超过 15 分钟 | 持续 | 任务表与 worker 指标 |
| 任务结果完整性 | 成功、失败、跳过计数与逐项结果一致 | 每次任务 | Content 数据库/审计 |

错误预算：列表可用性每 30 天最多 1% 失败。超过预算时暂停扩大发布范围，优先关闭任务准入并回退应用版本。
