# 产品规格：中老语言内容管理

> 状态：已批准｜版本：1.0｜日期：2026-09-04  
> 功能：`chinese-lao-content-hierarchy`｜规模：大型  
> 相关资料：[用户旅程](./journeys/journeys.yml) · [线框稿](./wireframes/) · [研究资料](../research/README.md)

## 一、概述

后台运营人员当前只能管理老挝语字母，无法完整维护两种语言的教学知识链，也无法从导航直接进入每个内容类别。V1 建立独立的中文与老挝语管理路由、结构关系编辑、现有修订审核发布流程的复用，以及发布前依赖校验。

## 二、用户

主要用户是获授 Content 权限的后台运营人员。角色与权限由既有 Operations 自定义角色体系配置；类别级读写、审核、发布权限键已由 D-164 确定，不预置固定业务角色矩阵。

## 三、范围与边界

| 语言 | 首期层级 |
| --- | --- |
| 老挝语 | 字母 → 音节 → 词语 → 句子 |
| 中文 | 拼音 → 中文音节 → 汉字 → 词语 → 句子 |

中文与老挝语的结构表、关系表、API 路径与后台页面分开；仓储和用例可复用不削弱语言边界的通用版本编排，`content.contents` 与 `content.content_revisions` 仍共享，仅承载统一身份和版本工作流。中文音节是语言知识实体，不是音频资源；Audio 继续拥有音频生产。每个类别页面是正式侧边栏路由，由统一递归目录自由组织。<!-- menu CR-004 -->

## 四、必须用户故事

- **US-001**：作为内容运营人员，我要从侧边栏进入中文拼音和中文音节管理，以维护中文基础发音知识。
- **US-002**：作为内容运营人员，我要维护中文汉字、词语、句子及其有序组成关系，以发布一致的中文教学内容。
- **US-003**：作为内容运营人员，我要维护老挝语字母和音节及其组成关系，以发布符合拼写规则的内容。
- **US-004**：作为内容运营人员，我要维护老挝语词语和句子及其组成关系，以完成老挝语教学链。
- **US-005**：作为审核或发布人员，我要查看版本差异和发布阻塞原因，以安全地审核和发布同语言内容。

## 五、功能需求

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| PRD-001 | 菜单注册中文六类和老挝语五类页面；每项是独立路由。 | 必须 |
| PRD-002 | 每种语言的结构表、关系表、仓储、接口和类别页面保持隔离；跨语言结构关系必须拒绝。 | 必须 |
| PRD-003 | 类别页支持列表、搜索、状态筛选、创建、工作版本编辑、版本比较、关系编辑及反向引用查看。 | 必须 |
| PRD-004 | 已发布内容仅能从当前发布版本派生工作版本；复用既有版本生命周期。 | 必须 |
| PRD-005 | 提交审核和发布时，在服务端校验实体完整性、关系顺序、同语言边界、依赖发布状态和乐观锁。 | 必须 |
| PRD-006 | 发布失败返回可定位的阻塞项；不得部分静默发布。 | 必须 |
| PRD-007 | 成功创建、编辑、审核和发布均经过 Operations 授权并记录成功操作审计。 | 必须 |

## 六、导航

`内容管理 → 中文内容 → 拼音/中文音节/汉字/词语/句子/审核发布`；`内容管理 → 老挝语内容 → 字母/音节/词语/句子/审核发布`。内容管理概览可保留为根路由。详见 D-163。

## 七、非功能需求

- 使用现有 Admin AppShell、DataTable、Dialog、StatusBadge、ConfirmDialog 和设计令牌。
- 页面必须提供加载、空、错误、发布阻塞、审核驳回与乐观锁冲突恢复状态；关键操作键盘可达且不只用颜色表达状态。
- 不修改冻结迁移；新增结构必须用前向迁移和对应数据库验证。

## 八、不在范围内

<!-- CR-001：中文新结构不做旧版运行兼容 -->
移动端和学习者端、音频生产与资产管理、跨语言通用结构表、自动分词或自动拼读建模、批量发布包、固定角色矩阵、旧版接口或旧数据模型运行兼容，以及中文音节字段与关系的未获批准细节。

## 九、成功标准

1. 运营人员可从侧边栏访问全部 11 个类别页，并在两种语言间不发生结构数据混用。
2. 所有类别都可经过草稿、审核、发布和历史版本追溯；依赖不完整或版本冲突不能发布。
3. 中老内容操作均经授权和审计，且 V1 不新增移动端或 Audio 生产行为。

## 十、风险与未决问题

- 中文音节及拼音到音节的字段、基数、顺序和迁移已由 D-164 与 Content/Database 权威契约确定。
- Content 类别权限键和自定义角色分配规则已由 D-164 与 Operations 权威契约确定。
- 汉字—词语、词语—句子的关系基数与编辑规则已由 D-164 与 Content 权威规格确定。

## 十一、决策记录

| 决策 | 理由 | 日期 |
| --- | --- | --- |
| 中文音节为独立知识实体 | 用户确认“发音 = 中文音节”，不与音频混同 | 2026-09-04 |
| 结构表隔离，身份与版本表共用 | 保留语言边界并复用稳定的 Content 基础设施 | 2026-09-04 |

| 类别页均为侧边栏路由 | 避免页面内导航；目录层级由运营人员自由组织 | 2026-09-04 |
| 新中文结构一次性切换，不做旧版兼容 | 用户明确要求 | 2026-09-04 |
