# ZH-LAO

ZH-LAO 是中文–老挝语综合学习与跨语言社交应用。学习负责获客与留存，社交负责关系形成，商业化方向主要围绕社交效率和虚拟礼物。

## 当前阶段

PostgreSQL Baseline、Application Foundation、Admin Foundation、Mobile Foundation、Identity、Platform 与 Operations 已完成并通过 Gate；当前主任务为 `CONTENT-BACKEND-PREP`。权威状态和下一动作请读取[项目知识入口](docs/PROJECT.md)。
