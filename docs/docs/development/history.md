# 历史实施证据

`development/01-foundation/` 至 `development/07-audio/` 保存旧 Phase 模型下形成的计划、设计审计、执行简报、实施报告和 Gate 证据。它们继续用于审计与历史追溯，但不再授予当前任务权限，也不得作为当前动态调度来源。

## 当前实施目录

- Backend 新工件写入 [`development/backend/`](backend/)。
- Admin 新工件写入 [`development/admin/`](admin/)。
- Mobile 新工件写入 [`development/mobile/`](mobile/)。
- Task、Claim、Gate 与 Handoff 控制工件写入 [`development/workflow/`](workflow/)。
- 当前流程、状态和调度分别读取[开发流程控制中心](DEVELOPMENT_CONTROL_CENTER.md)、[开发进度记录表](DEVELOPMENT_PROGRESS.md)和[当前下一动作](workflow/NEXT_ACTIONS.md)。

## 原位保留目录

- `01-foundation/`：Application Foundation 计划与完成证据。
- `02-identity/`：Identity 设计、实施与回归证据。
- `03-platform/`：Platform Backend 与 Admin Stage A 证据。
- `04-operations/`：Operations 设计与实施证据。
- `05-content/`：Content 设计、执行准备与受阻 Admin 证据。
- `06-learning/`：Learning 设计与实施准备证据。
- `07-audio/`：Audio 设计、恢复与实施准备证据。

这些目录保持原路径，不移动、不删除。历史文档中的阶段判断按当时仓库状态理解；需要判断当前状态时必须回到现行 authority 链。
