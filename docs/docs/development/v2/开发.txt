# 六、已经冻结的安全规则

## OTP

```text
OTP length = 6 digits
TTL = 5 minutes
Max attempts = 5
Cooldown = 60 seconds

Phone/purpose:
5 requests / 30 minutes
10 requests / 24 hours

IP:
20 requests / 30 minutes
```

OTP：

```text
raw OTP never persisted
raw OTP never logged
```

低熵 OTP 必须使用 keyed HMAC / MAC 类安全校验。

不得改成普通 SHA256 直接 hash。

OTP 成功消费不是 reusable verification ticket。

必须与实际业务操作原子绑定。

# 七、Session / Token 冻结规则

```text
Access Token = JWT
Access TTL = 15 minutes

Refresh Token = opaque cryptographically random
Refresh Rotation = ALWAYS

Session TTL = 30-day sliding
Raw Refresh Token persisted = NEVER
```

数据库只能保存 refresh hash。

成功 refresh：

```text
old refresh token immediately invalid
new refresh token generated
session expires_at = now + 30 days
```

并发使用同一个旧 refresh：

```text
success count <= 1
```

当前 V1 没有：

```text
Access Token blacklist
Refresh token family
Replay history
```

不要新增。

Session / Device revoke：

立即阻止 refresh。

已签发 Access JWT 最多还可能存活约 15 分钟。




