# 产品画像

## 一句话

ZH-LAO 是面向中文用户和老挝语用户的双语学习与跨语言社交应用。

## 价值路径

```text
学习内容 → 用户增长与留存 → 双边用户池
→ 动态 / 发现 / 主页 → Follow → Mutual Follow → Match
→ 免费聊天与跨语言辅助 → 关系和活跃
→ 社交权益与虚拟礼物
```

学习和社交可以独立使用；社交资料、发现、Match 和聊天有独立准入与安全治理。

## 产品组成

- 移动端：普通用户的登录、学习、社交、聊天、钱包和设置体验，首发重点为 Android。
- 运营后台：内容维护、音频生产、平台配置、权限和审核运营工作台。
- 后端与 PostgreSQL：共享业务核心和按 Domain 划分的持久化事实。

## 首期范围摘要

包含中文/老挝语学习内容、课程、练习、词典、发音、进度、社交资料、发现、动态、聊天和安全运营能力；游戏化、视频动态、文件/视频/语音通话等不在当前首期边界。具体范围和例外以[产品定位与范围](/developer/reference/product/product-overview)、[业务与商业模型](/developer/reference/product/business-model)和[功能开放与规则](/developer/reference/product/feature-rollout)为准。

## 当前成熟度

项目仍处于开发阶段，不是可正式发布的完整产品。数据库和若干 Foundation、Identity、Platform、Operations 基础能力已经有 Gate 证据；完整学习、社交、聊天、商业、安全和系统发布旅程仍需按交付状态核验。
