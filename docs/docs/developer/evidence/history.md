# 开发资料阶段历史

旧 `development` 树曾按 Foundation、Identity、Platform、Operations、Content、Learning、Audio 及 Backend/Admin/Mobile 工作轨记录计划、契约、Gate 和报告。它服务过阶段执行，但不再作为当前文档入口或调度权限。

迁移保留的少量契约与证据快照位于 [Identity API 契约](../reference/contracts/identity/IDENTITY_API.md) 和 [Platform 设计证据](../reference/evidence/platform/PLATFORM_DESIGN_AUDIT.md) 等页面，每份文件都标明其快照性质。其余计划、报告、Task Manifest、旧 Gate 和旧自建 Spec 文档仅由 Git 历史保留。

需要复核某一历史状态时，使用 Git 查看对应提交、文件路径和报告日期，并与当前代码、测试、CI、`.specify/` 和 `specs/` 对照；不要把历史记录直接当作当前状态。
