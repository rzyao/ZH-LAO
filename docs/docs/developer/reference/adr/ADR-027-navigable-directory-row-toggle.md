# ADR-027：可导航目录整行点击同步伸缩

**状态：** `已接受`

**日期：** `2026-09-04`

**批准：** 用户明确要求二级菜单项目本身可以伸缩，登记 D-166 / Product Forge CR-005。

**修订：** [ADR-026](ADR-026-unified-recursive-admin-menu-tree.md)、设计台账 D-165

## 决策

带路由且含子节点的目录，其菜单项目整行点击必须同时执行路由跳转和当前目录展开/收起。
右侧箭头继续作为独立的纯伸缩操作，不触发路由跳转。纯目录节点继续由整行点击伸缩。

可导航目录项目必须暴露 `aria-expanded`，使键盘和辅助技术用户获得与鼠标用户一致的状态。
侧边栏整体折叠到仅图标状态时，点击节点只执行路由跳转，不改变隐藏目录的展开状态。
菜单名称与箭头必须位于同一个视觉行容器；激活态背景、左侧高亮边和悬停反馈覆盖整行，
不得只高亮菜单名称而把箭头留在选中区域之外。

## 后果

- 操作员不必精准点击小箭头即可浏览二级及更深目录。
- 点击可导航目录可能同时改变主内容与侧边栏展开状态，这是本交互的预期行为。
- 箭头仍适合只想查看子菜单而不离开当前页面的操作员。
