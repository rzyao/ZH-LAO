# Admin 导航结构

后台侧边栏导航**配置驱动**渲染（ADR-022 / ADR-026）：菜单结构由运营人员在后台「菜单与路由管理」页面（`/platform/menus`）在线维护，运行时从后端 `platform.menus` 拉取并递归渲染；配置加载失败时回退内置安全默认导航。

所有菜单节点使用同一种模型，不再区分分组、一级菜单或子菜单。无路由节点是目录；带路由节点也可以继续拥有子节点。目录允许自由嵌套，含子节点的目录在每一层都默认收起，即使当前路由位于其中也不自动展开。目录名与页面名统一使用正常导航字号。带路由且含子节点的目录点击菜单项目时同时跳转和伸缩；右侧箭头只伸缩、不跳转。菜单名称与箭头属于同一个视觉行，选中背景和左侧高亮边覆盖整行。<!-- CR-005: 二级菜单整行点击伸缩 -->

新增后台页面必须以页面职责、权限、API 和审计要求为中心登记,并在[页面清单](pages.md)和关联 Feature Page 中形成双向关系;同时需在代码中的 `route-registry.ts` 白名单与菜单 seed 配置中登记目标路由。
