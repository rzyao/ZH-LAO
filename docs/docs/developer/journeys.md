# 用户旅程

本页只描述现有产品文档中的旅程骨架；每一步是否已经交付，必须回到[交付状态](delivery-status)和对应 Feature Page 核验。全景覆盖的 103 个功能按旅程能力分组，完整入口见[功能目录](features/)。

## 学习者旅程

```text
选择界面语言
  → 游客浏览学习内容
  → 手机号或 Facebook 注册
  → 选择学习方向
  → 学习课程、字母、词汇、发音和练习
  → 查看进度与复习
```

## 跨语言社交旅程

```text
完善社交资料
  → 满足准入与必要审核
  → 发现和筛选合适的人
  → 关注 / 互相关注 / Match
  → 动态互动或打开会话
  → 文字、图片及规划中的语音和翻译辅助
```

学习资格不自动授予社交资格；位置用于距离计算与模糊展示，不向用户暴露精确坐标。

## 内容与运营旅程

```text
内容人员创建或编辑内容
  → Revision / 审核 / 发布
  → 移动端只投影可见的已发布内容
  → 运营人员通过 RBAC 执行配置、审核和审计
```
