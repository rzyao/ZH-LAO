# 当前重点

## 已核验事实

迁移时核验基线 `8f3237e` 已包含 Lao Alphabet 的 Backend、Admin 和 Mobile 实现；该局部功能的验收仍待补齐。它不能代表整个 Content Domain 已完成，也不自动授予其他领域执行权限。

## 当前最大缺口

- 103 个功能页中，除登录与字母管理两个试点外，还有 101 个尚未按统一契约完成人工分层核验。
- 字母管理已有代码和基础测试证据，但 Integration 与 Acceptance 仍待补齐。
- 学习、社交、聊天、商业、安全和全产品发布旅程尚未整体验收。

## 如何建立下一条工作项

1. 从[功能目录](features/)选择一个明确的用户或运营能力，并阅读对应 Feature Page。
2. 查阅对应 Reference 领域、契约和当前代码/测试，确认范围、依赖和实际缺口。
3. 在 `.specify/` 与 `specs/` 中建立或更新 Spec Kit 工件；不要从旧阶段名称或旧任务清单恢复任务。
4. 让代码、测试和 CI 产生可复核证据，再回写功能页的分层状态。

本页是人类摘要，不授予任务权限。具体变更必须以当前 `.specify/`、`specs/`、代码、测试和 CI 核验为准。
