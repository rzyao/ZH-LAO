# Syllable Domain（老挝语音节）

> 状态：Domain Framework Draft  
> 领域：Content Domain  
> 职责：定义老挝语音节的拼读结构、正字法切分规则、字母组成链、发音转写机制及音节生命周期。

---

## 1. 领域范围与核心实体

### 1.1 实体概念：LaoSyllable [PA]
音节是老挝语从字母过渡到词汇的拼读与发音核心单元。老挝语书写无天然音节空格边界，音节承载了正字法拼接和声调组合的基本规则。

### 1.2 核心属性定义 [PA]
- **音节文本（lao）**：老挝语音节的书写形式（Unicode 码点级精确匹配）。
- **音标（Phonetic）**：ASCII 拼读风格发音音标（如 `khoy`, `bai`, `khao`），用于学习者拼读辅助。
- **中文释义 / 描述**：音节对应的字面含义或教学说明（部分单音节直接具备词义）。
- **录入来源（Source）**：
  - `manual`：教学专家人工录入。
  - `word-auto`：录入单词时由算法拆分建议并经确认自动建档。

## 2. 音节正字法与切分规则 [PA]

### 2.1 音节结构模型
老挝语音节的标准语言学结构为：
$$\text{Syllable} = (C)(C)V(C) + \text{Tone Mark}$$

### 2.2 权威切分规则（Lao Syllabification Rules）
算法与校验层遵循 6 大正字法切分权威规则：
1. **附属标记原则**：元音符号、声调符号、连字符（如 `ຼ`）直接附属于当前音节。
2. **声母/韵尾判定**：辅音后接元音符号时判定为新音节声母；辅音后无元音时判定为当前音节韵尾。
3. **特判字符 ອ**：
   - 当 ອ 后紧跟元音符号时，ອ 作为声母发音；
   - 否则，ອ 作为元音 `/ɔ/` 符号使用（如 ຂ້ອຍ / ຂອງ）。
4. **特判字符 ວ**：
   - 紧跟在 `ກ` / `ຂ` / `ຄ` 之后且后接元音符号时，构成介音复辅音（`ກວ` / `ຂວ` / `ຄວ`）；
   - 否则按普通辅音处理。
5. **前引元音先行书写规则**：
   - 前引元音（`ເ`, `ແ`, `ໂ`, `ໃ`, `ໄ`）在视觉书写上置于声母之前，但在音节逻辑上附着于其后的辅音声母（如 `ກິນເຂົ້າ` $\to$ `ກິນ` | `ເຂົ້າ`）。
6. **复合声母正字法**：
   - 识别由 `ຫ` 引导的复合声母：`ຫງ` / `ຫຍ` / `ຫນ` / `ຫມ` / `ຫລ` / `ຫວ`。

## 3. 音节↔字母组成链与严格一致性 [PA]

### 3.1 有序组成链（Ordered Character Sequence）
- 音节与字母之间建立有序组成关系。
- 组成关系必须**保留重复项**（如包含多个相同元音或辅音时按序保留）。
- 组成快照在内容发布时随修订版本一起冻结。

### 3.2 严格拼接一致性校验（Rule 4404）
- 音节内的组成字母按次序拼接，其字符串必须与音节原生书写完全一致：
  $$\text{Concatenate}(\text{Letters in Sequence}) \equiv \text{Syllable Text}$$
- 违反拼接一致性校验的音节将被拒绝保存（错误码 4404）。
- 巴利语/梵语借词等生僻特殊拼写如自动切分不准，允许人工修正组成序列，但必须满足拼接一致性。

### 3.3 依赖生命周期约束
- 所依赖的全部字母必须处于已审核通过（Approved/Published）状态，否则音节不得通过审核。

## 4. 音标转写规则（Transcribe Logic）[PA]

### 4.1 转写风格
- 音节音标采用 **ASCII 拼读风格**（区别于字母的 IPA 音标）。
- 音标生成基于组成字母的 IPA 音标与正字法规则自动生成初稿，并由人工审核最终裁定。

### 4.2 核心变读与拼写映射规则
- **IPA $\to$ ASCII 基础映射**：如 `aː` $\to$ `aa`, `ɯ` $\to$ `eu`, `ɤ` $\to$ `oe`, `ɔ` $\to$ `o`。
- **ອ 词首静音处理**：ອ 位于音节首位作声母时不生成辅音音素。
- **韵尾变读映射**：
  - `ບ, ດ, ຈ, ສ, ທ, ຖ, ພ, ປ, ຝ` 作为韵尾时统一转写为入声塞音 `/p/` 或 `/t/`；
  - `ຣ, ລ` 作为韵尾时转写为鼻音 `/n/`。
- **双元音与韵尾合规拼写**：
  - `aa + ຍ` $\to$ `ai`, `aa + ວ` $\to$ `ao`, `o + ຍ` $\to$ `oy`, `i + ວ` $\to$ `iu`；
  - 闭音节韵尾前 `ii` $\to$ `i`, `uu` $\to$ `u`（呈现 `jin`, `hup` 拼读形态）。
- **复合元音序列表**：支持 16 组复合元音的正字法转写（如 `ເົາ` $\to$ `ao`, `ົວ` $\to$ `ua`, `ເຍ` $\to$ `ia` 等）。

## 5. 发音与音频契约 [PA]

- 每个正式音节对应 1 个老挝语发音槽位（`lo/pronunciation`）。
- 声调符号虽附属音节，但音节的拼读 ASCII 音标默认不体现声调数字，声调知识主要由真实音频呈现。

## 6. Engineering Reality 历史映射 [ER]

> 仅记录旧系统事实备查，不作为新系统架构依赖：
- 旧系统落点于 `app_syllable` 主表，通过 `app_syllable_letter` 维护多对多有序关系。
- 存量数据共 261 行音节。
- 历史早期存储过程 `insert_syllable_item_records` 随旧单元表已废弃删除，音节生成逻辑完全收敛至应用服务层。
