# ZH-LAO 文档中心

`PROJECT.md` 是仓库级项目知识总入口；本站从下列主题进入。

- [产品](product/product-overview.md)：定位、范围、业务模型、商业模式和功能开放。
- [架构](architecture/overview.md)：总体架构、Domain Map 和 PostgreSQL 规范。
- [领域设计](domains/README.md)：十个领域的模型、流程与数据库状态。
- [治理](governance/design-register.md)：设计台账、未决事项和来源覆盖。
- [ADR](adr/README.md)：长期架构决策与取舍。

仓库维护规则见根文档目录的 `AGENTS.md`。只有 `baseline` 和 `frozen` 内容属于当前实现依据；`designing` 与 `deferred` 不得被实现者自行补全。
